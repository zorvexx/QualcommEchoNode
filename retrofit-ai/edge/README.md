# RetroFit Edge AI Deployment Artifacts (Arduino Uno Q)

This directory contains edge deployment assets generated by `scripts/train_model.py`:

## Directory Layout
* `model/`
  * `scaler.pkl`: StandardScaler / RobustScaler fitted strictly on baseline healthy machine features.
  * `state_model.pkl`: GMM / KMeans Operating State classifier.
  * `anomaly_model.pkl` / `anomaly_model.onnx`: INT8 ONNX or PyTorch model for edge inference.
* `config/`
  * `selected_features.json`: Ordered list of active pruned features (30 features).
  * `machine_fingerprint.json`: Machine-specific behavioral baseline distribution and thresholds.

## Uno Q Runtime Workflow
1. STM32 MCU handles low-level I2S (audio DMA) and SPI (MPU9250 IMU) sampling.
2. Qualcomm Linux Processor loads artifacts from `edge/model` and `edge/config`.
3. Qualcomm Linux SoC runs `src/inference/inference.py` every 1.024s hop window.
